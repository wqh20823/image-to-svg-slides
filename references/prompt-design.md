# 内容与图片提示词

## 页面规格

先提取可用信息，再决定图表和版面。在工作过程目录记录页面任务、观众需要记住的一点、准确文案、关键数字及单位、事实状态、素材作用、阅读顺序和主图占比；不自动把规格变成交付物。

只有用户要求内容策划时才重组文案。对已有页面做转换，不借机改内容。网页信息、版本、政策和企业介绍需要补充时按当前工具规则核实，优先权威来源；纯转换不需要联网。

## 信息密度与视觉层级

正式汇报可以图文丰富，但每个区域应有清楚的作用。用一幅主图配有限的支撑信息，避免满页等权重卡片、重复摘要、长段落和无意义装饰。

无模板时可从下列数值开始，再按内容调整。单位是 1920×1080 坐标，不是印刷点数：

| 项目 | 建议起点 |
|---|---|
| 左右安全边距 | 60–90 |
| 模块间距 | 20–32 |
| 模块内边距 | 20–28 |
| 主标题 | 48–60 |
| 分区标题 | 30–36 |
| 正文／图表标签 | 26–32 |
| 次要注释 | 20–24 |
| 正文行距 | 字号的 1.2–1.4 倍 |

用户模板与参考图优先。图表密集时可降低次要标签字号，主要信息不能依赖小字才能理解。不将标题、正文、注释一起缩小来塞满内容。

一页优先用一至两种字重、两至三个主字号、一个主色和少量强调色。图标用同一套线性或面性风格。图片要支撑解释或证据，不为凑密度添加人物照、奖状或科技装饰。

短标题可说明主题，也可表达有证据支持的结论，不强行写成广告口号。写具体对象和作用，少用没有内容支撑的“赋能、闭环、全栈、颠覆、生态”等词。

## 提示词结构

每页提示词应能脱离聊天独立使用。下面是写作结构，所有字段替换成真实内容并删除不适用项，不交付未填写的占位符。

```text
生成一张完整的图片版幻灯片，16:9 横版，正视、平面、单页。
画面目标：[页面内容与主要视觉重点]。

参考素材：
图 1：[编辑底图或模板；必须保留的区域、标志、颜色]。
图 2：[仅参考排版或视觉风格，不引用其内容]。
图 3：[必须插入的图或标志，保留细节、方向和比例]。

视觉规格：
[背景、主色、字体类型、字重、边距、分区、主图位置与占比]。
[跨页导航、标题基线、品牌元素等需要保持一致的项目]。

页面内容（逐字呈现）：
标题：[完整文字]
[区域 1 的标题、正文、数字、单位]
[区域 2 的标题、正文、数字、单位]
[图表轴、图例、节点、连线方向及数据]

布局关系：
[按阅读顺序描述，列出列宽比例、对齐线、层级与留白]。
[哪个部分为主视觉，哪些文字仅为解释，不重复呈现同一句话]。

绘制要求：
中文文字清晰准确。主次分明，不重叠、不溢出、不挤压成小字。
图标规整、线宽统一、圆形同心、对称图形左右一致。
数据图表按给定数据绘制，标注事实或目标的状态。
不添加未提供的成绩、客户、证书、人物、标志或宣传口号。
不绘制电脑外壳、投影屏幕、演示现场、透视效果或多页拼图。
输出只有这张完整幻灯片。
```

有指定分辨率时写入目标，但以生成文件真实尺寸为准。不要把“矢量风格”误当成工具能够返回 SVG。

## 多页一致性

固定页面比例、标题基线、导航位置、标志大小、基础线宽与字体系统，允许内容版式变化。第一张满意的图可作为后续风格参考；逐页给出准确文案，不能只写“按上一页风格继续”。

演讲时长只在用户指定时影响安排。预计讲述时间放在私有规划或用户要求的备注中，不自动写到画面。不因页数较少擅自添加封面、目录、总结或过渡页。

## 生成后核对

按提示词读出每个标题、节点、数字与单位。特别核对相近汉字、专有名词、负号、小数点、希腊字母、上下标和英文大小写。

生成图片的错字不能成为 SVG 底稿，以确认文案修正。版式良好但一处文字错误时优先局部修正；已授权 SVG 阶段可用真实文字纠正，不反复生成整页。若用户也需要准确的图片版成品，最终图片同样要修正并复查。
