# SVG 精细重建

## 输入与坐标

查看完整原图，从源 PPTX 或现有 SVG 获取可复用文字、标志、图表和架构图，优先于从像素反推。记录分区边界、对齐线、标题基线、色板及文字框，分清背景、容器、连线、图标、正文和图片。

纯截图转换默认保留截图比例。已确认 16:9 而源图只有一两个像素误差时可用精确 16:9 画布，以等比例放置／重建消化差异，不能横向拉伸。

统一逻辑坐标，例如 `viewBox="0 0 1920 1080"`。输出 width / height 可等比例放大，字体和图形设计仍基于 viewBox。先做布局再做细节，按对象功能重建，不按扫描行堆砌数万个微小路径。

## 可编辑对象

| 内容 | SVG 表达 |
|---|---|
| 正文、标题、数值、标签 | 真实 text / tspan，Unicode 文字 |
| 容器、分隔线、表格单元格 | 独立 rect / line，文字另置 |
| 箭头、折线、图标 | 独立 path / polyline / polygon / 圆形等 |
| 架构、流程、平台界面 | 节点、图标、标签、连线按语义分组 |
| 数据图表 | 从原数据绘制可编辑坐标轴、曲线、标记、图例与标签 |
| 标志 | 优先原始 SVG，可保留路径，不按普通文字重排商标 |
| 照片、复杂纹理 | 用户允许时保留独立 image，可移动、缩放、替换 |

整页 PNG 放入 SVG、截图叠透明字、全部文字变轮廓、整页自动像素描摹，都不满足可编辑要求。

图表原数据缺失时可忠实重建可见线条和标签，但不编造数据或声称恢复了数据；影响结论的数值不确定性先确认。

## 文字与字体

- 使用环境实际安装的字体。中文可用微软雅黑、思源黑体或 Noto Sans CJK；确认字体文件后测量，不按字符数量估算中英混排宽度。
- 按语义换行，使用明确 x、y 或 tspan。每个逻辑文本框独立，不给每个汉字造一个对象。
- 根据实际字体度量核对行宽与内边距。放不下先优化换行或框宽；内容策划模式才可精简文案。不默认用 textLength / lengthAdjust 压扁文字。
- 留出字体替换余量，不用裁剪蒙版掩盖文字溢出，不靠 overflow:hidden 通过检查。
- 避免 foreignObject、HTML、依赖网页 CSS 的排版。关键位置优先明确基线，不依赖各编辑器解释不同的 dominant-baseline。
- 不嵌入无授权字体；不为保真擅自将文字转轮廓。

## 图形、图标和连线

- 圆形同心；齿轮齿数、半径与角度统一参数化，不徒手逐点拼歪。
- 组内统一线宽、端点、圆角和视觉重量。小图标简化线条，不挤压复杂细节。
- 在共同坐标盒内绘制，再等比例移动和缩放；比较视觉大小，不只比较外框尺寸。
- 箭头优先直线或正交折线，方向正确，尖端接近目标边界而不覆盖文字。先确定连接点再布线。
- 普通折线配独立三角箭头便于编辑，不用字体箭头替代关键流程线。
- 显示器、文档、人物、地图点位、列表等界面示意拆成独立图形，不把小窗口保留为截图。

## 标志、照片和复杂背景

先从用户原模板或合法提供的源资产取得标志。不要把生成工具画错的标志当原图，也不要用相近字体伪造。无矢量源且外形必须精确时，保留独立图像并说明边界；用户要求每条路径都可编辑时，继续寻找合适素材或取得所缺源文件。

已确认保留照片原貌时不重复询问，也不描成大量色块。使用自包含 PNG/JPEG data URI，保持比例并分组。照片内容不能宣称逐像素可编辑。

为 image 写 `data-asset-role="photo"`、`"logo"` 或 `"complex-background"`，另写 `data-editability="image-object"`。背景图不得含本应拆分的正文、图表或界面。纯图文页默认没有嵌入位图。

## 文件与兼容性

- SVG 命名空间：`http://www.w3.org/2000/svg`。
- Inkscape 命名空间：`http://www.inkscape.org/namespaces/inkscape`，图层使用 inkscape:groupmode="layer" 和 inkscape:label。
- 顶层按背景、页眉、标题、主图模块、说明等分组，内部再分图形与文字。名称描述内容，不写处理过程。
- ID 唯一。导入外部 SVG 时给 ID 及 url(#...)、href="#..." 同时加前缀，避免渐变、裁剪和标志冲突。
- 优先内联展示属性、基础渐变和普通图形。减少嵌套变换，避免滤镜、遮罩、脚本、外部链接资源和不必要的 use 实例。重复符号需确认能独立改动。
- SVG 自包含，不依赖临时路径、浏览器资源或字体图标服务。
- SVG 编辑器可编辑不等于 PowerPoint 转成形状后仍保留文字。未实测不得承诺；要求原生 PPT 对象时另建文本框与图形并检查。

## 辅助构建工具

scripts/svg_slide.mjs 无第三方依赖，提供唯一 ID、XML 转义、分组、图层、多行文字、形状、网格、箭头和对称齿轮。在私有构建目录导入：

```javascript
import { pathToFileURL } from 'node:url';
const skillModule = '/absolute/skill/path/scripts/svg_slide.mjs';
const { SvgSlide, grid } = await import(pathToFileURL(skillModule).href);
const s = new SvgSlide({ width: 1920, height: 1080, title: '页面标题' });
const box = grid({ x: 72, y: 220, width: 1776, height: 650, columns: 3, gapX: 24 })[0];
const content = s.group('能力模块', [
  s.rect(box.x, box.y, box.width, box.height, { fill: '#F1F7FD', stroke: '#B9D8EF' }),
  s.text(box.x + 24, box.y + 54, ['模块标题', '准确的说明文字'], {
    size: 32, lineHeight: 44, maxWidth: box.width - 48, fill: '#123765'
  })
], { layer: true });
const svg = s.render([content]);
```

工具不自动决定版式、换行或数据，也不保证兼容所有编辑器。输出保存到任务目录，随后检查结构、渲染并查看。
